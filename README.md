# StockFlow – B2B Inventory Management System

## Structure

- **part1/** – Code review & debugging of the product creation endpoint
- **part2/** – Database schema design and requirement analysis
- **part3/** – Implementation of low-stock alert API (Node.js/Express)

## Highlights

- **Part 1:** Fixed critical data integrity issues, enforced SKU uniqueness, and aligned with multi-warehouse requirements.
- **Part 2:** Designed a normalized, scalable schema with clear constraints and identified key missing requirements.
- **Part 3:** Built a production-ready low-stock alert endpoint with proper error handling and realistic assumptions.
